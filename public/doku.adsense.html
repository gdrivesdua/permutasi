1. Cara Masuk ke AdSense Studio (/adsense-studio/)

Buka alamat /adsense-studio/ di browser Anda (atau klik tab Layout & AdSense dari header Article Studio). Layar masuk menggunakan password editorial terpadu yang sama dengan Article Studio, Admin Lexicon, dan Database D1 (/admin-data/).

Prinsip Slot Bersih: Pada halaman publik pengunjung, slot iklan yang masih kosong, masih memakai mode Simulasi Studio, atau dinonaktifkan otomatis disembunyikan total. Pengunjung tidak akan pernah melihat kotak putus-putus atau ruang kosong sebelum kode AdSense asli dipasang.

3. Langkah Memasang Kode AdSense per Slot

  1. Isi Publisher ID Global (Opsional): Masukkan ID penerbit Anda (format ca-pub-1234567890123456) pada kolom Publisher ID Global di panel kiri atas. Ini berguna sebagai cadangan otomatis bila cuplikan slot tertentu tidak mencantumkan data-ad-client, sekaligus dipakai untuk membangun berkas /ads.txt.
  2. Buka Kartu Slot yang Ingin Diatur: Klik nama slot atau tombol Atur di panel Konfigurasi Slot AdSense. Pastikan kotak centang Aktif dalam kondisi tercentang.
  3. Tempel Cuplikan Kode dari Google AdSense: Salin kode unit iklan dari dashboard Google AdSense (boleh menyertakan blok <script> dan <ins class="adsbygoogle" ...> lengkap), lalu tempel ke kolom Cuplikan Kode AdSense.
  4. Verifikasi Status Parser: Di bawah textarea akan muncul status biru seperti Terdeteksi aman: ca-pub-... · slot 1234567890. Studio secara otomatis mengekstrak atribut data-ad-client, data-ad-slot, data-ad-format, data-ad-layout, dan data-ad-layout-key dengan aman, serta otomatis mengarahkan Mode Pratinjau Studio ke Kode AdSense Asli (<ins>).
  5. Pilih Ukuran & Margin: Pilih preset Ukuran Desktop dan Ukuran Mobile yang sesuai dengan jenis unit iklan yang Anda buat di AdSense, serta atur Margin Atas dan Margin Bawah (minimal 20px, default 24px, maksimal 64px) agar iklan tidak menempel pada teks atau tabel.

4. Mengatur Unit Khusus Bahasa Tertentu (Opsional)

Untuk halaman multibahasa (Front Page, Guide, dan FAQ), di bagian atas form tiap slot terdapat pilihan Cakupan Bahasa Kode Iklan:

  • Semua Bahasa (Default Global): Satu kode slot dipakai seragam untuk seluruh 8 edisi bahasa.
  • Khusus Bahasa Tertentu (EN / ID / ES / PT / FR / DE / RU / JA): Jika ingin memantau performa atau menonaktifkan slot hanya pada bahasa tertentu, pilih bahasanya di dropdown cakupan lalu tempel cuplikan khusus atau ubah status Aktif-nya. Untuk membatalkan dan kembali memakai pengaturan global, klik tombol Ikuti Default.

5. Uji Pratinjau Desktop vs Mobile & Margin

Di kolom kanan studio, gunakan switcher Desktop (Kolom Konten) dan Mobile (390px) untuk memeriksa posisi iklan relatif terhadap teks, tabel, dan tombol navigasi:

  • Pada tab Artikel, Anda juga dapat memilih artikel sampel di dropdown Artikel Pratinjau, menguji tombol kontrol huruf terpadu pengunjung A− / A+ (85%–130%) di kanvas, serta menyetel skala huruf bawaan per bagian melalui panel Skala Font Bagian Artikel (Opsional) di kolom kiri.
  • Untuk Slot 5 (Anchor Ad), klik tombol tutup × untuk memastikan interaksi tutup bekerja rapi, lalu klik Tampilkan Anchor Ad (Slot 5) bila ingin memunculkannya kembali di pratinjau.
  • Pada tab Front Page, Guide, dan FAQ, gunakan dropdown Bahasa Pratinjau (8 Edisi) untuk memastikan judul dan override tiap bahasa tampil sesuai harapan.

6. Uji Lokal Browser vs Tayang Permanen untuk Semua Pengunjung

A. Simpan & Uji di Browser Admin (Sementara)

  1. Centang opsi "Terapkan unit AdSense aktif tersimpan saat membuka halaman situs live di browser ini".
  2. Klik tombol biru Simpan Konfigurasi di pojok kanan atas.
  3. Buka tautan Artikel Live (atau halaman Front Page/Guide/FAQ) di tab baru pada browser yang sama untuk melihat hasilnya sebelum dipublikasikan ke semua pengunjung.

B. Tayangkan Permanen ke Seluruh Pengunjung

  1. Klik tombol Salin Kode / JSON Konfigurasi di panel kiri.
  2. Klik Salin JSON pada bagian 1. JSON Konfigurasi.
  3. Tempel dan gantikan isi objek "googleAdSense" di berkas site.config.json pada repositori proyek (pastikan "enableAutoAdsScript": false bila tidak ingin memuat skrip Auto Ads di <head>; skrip adsbygoogle.js tetap dimuat otomatis hanya saat ada unit slot aktif).
  4. Commit & push ke GitHub. Build statis (npm run build) otomatis menanamkan unit <ins> yang valid langsung ke HTML statis serta menghasilkan berkas /ads.txt.

7. Checklist & Catatan Penting Admin

  • Pastikan ID penerbit (ca-pub-...) dan nomor data-ad-slot sudah aktif serta disetujui di akun Google AdSense sebelum di-commit ke site.config.json.
  • Untuk menonaktifkan sementara satu slot tanpa menghapus kodenya, cukup matikan centang Aktif pada slot tersebut lalu ekspor ulang konfigurasi ke site.config.json.
  • Jika ingin mengulang pengaturan awal di browser, gunakan tombol Reset Default di panel kiri studio.
  • Halaman dokumentasi ini (/public/doku.adsense.html) serta seluruh halaman admin (/admin-articles/, /adsense-studio/, /admin-lexicon, /admin-data/) dilindungi noindex, nofollow agar tidak terindeks mesin pencari.
